# Java Projects

This repository contains two Java-based projects designed for learning and practical implementation:

## Projects Overview

### 1. Calculator
**About:**
A simple Calculator application built using **Java Swing**. It is designed with easy-to-understand code to help beginners learn how to operate and build a calculator.

**Features:**
- Basic arithmetic operations (Addition, Subtraction, Multiplication, Division)
- Simple and intuitive GUI using Java Swing

### 2. Shopping Cart (E-Commerce Website)
**About:**
An online Shopping Cart system developed for selling electronic products. This project demonstrates a complete e-commerce workflow.

**YouTube Demo & Setup Guide:** [Watch Here](https://www.youtube.com/watch?v=RgQG0_orFpM)

**Features:**
- User registration and login
- Browse products, filter, and search by categories
- Add multiple items to cart with quantity adjustments
- Checkout process with demo credit card payment
- Order placement and tracking
- Email notifications for registration, order confirmation, shipping updates, and stock availability
- Admin functionalities:
  - Add, update, and remove products
  - Manage inventory
  - View and update order statuses (shipped/delivered)

**Note:**
The payment page is for demo purposes only and is not integrated with any real payment gateway. Any credit card details entered will be accepted for demonstration.

## Setup Instructions

### Calculator:
1. Clone the repository.
2. Navigate to the Calculator project folder.
3. Compile and run the Java files using your preferred IDE or command line.

### Shopping Cart:
1. Clone the repository.
2. Navigate to the Shopping Cart project folder.
3. Follow the setup instructions provided in the YouTube video linked above.
